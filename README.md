Plato Cafe is a modern mobile application designed to enhance the coffee ordering experience for South African customers. The app allows users to browse menus, place orders, earn rewards, and receive real-time notifications - all while supporting multiple local languages.
               Purpose
Digital Transformation - Modernize the coffee shop experience with mobile ordering
Customer Loyalty - Implement gamified rewards system to increase retention
Accessibility - Support for multiple South African languages (English & Sepedi)
Offline Capability - Order even without internet connection with automatic sync
Real-time Updates - Instant notifications for order status and promotions

Key Design 
1. MVVM Architecture - Chosen for separation of concerns and testability
2. Firebase Backend - Provides scalable authentication, database, and messaging
3. Room Database - Enables robust offline functionality
4. Multi-language Support - Built-in localisation framework for South African markets
